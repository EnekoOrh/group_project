\chapter{Discussion}

The report should interpret results using three axes:
\begin{itemize}[leftmargin=1.5em]
\item objective quality (area),
\item feasibility under constraints,
\item computational efficiency (evaluations and runtime).
\end{itemize}

Expected pattern for this task family:
\begin{itemize}[leftmargin=1.5em]
\item BFGS is typically efficient in evaluations when initialized near feasible basins,
\item SA can be robust in constrained landscapes due to probabilistic acceptance,
\item PSO provides exploration but may require larger budgets under strict penalties.
\end{itemize}

S8 should be treated as a bottleneck scenario if feasibility remains low under current penalty and budget settings.
