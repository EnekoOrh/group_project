\section{Selection and Compliance Semantics}


\noindent To keep Task 6 -> Task 7 interpretation unambiguous, each selected case carries its original status tier.

\noindent Task 6 mathematical compliance is tied to normalized target constraints:

\[
g_V = \frac{|V - V^*|}{V^*}, \qquad g_H = \frac{|H - H^*|}{H^*}
\]

\noindent A mathematically compliant case satisfies \(g_V \le \varepsilon_V\) and \(g_H \le \varepsilon_H\).

\noindent Engineering-feasible means mathematically compliant \textbf{and} passing the additional engineering plausibility checks from Task 6.

\noindent The Task 7 selection rule per scenario/optimizer pair is:

\[
\begin{aligned}
r^* &= \arg\min A(r) && \text{over engineering-feasible runs} \\
&\text{else }= \arg\min A(r) && \text{over mathematically compliant runs} \\
&\text{else }= \arg\min F_{pen}(r) && \text{(warning fallback only)}
\end{aligned}
\]

\noindent where \textit{A} is shell area and \textit{F\_{pen}} is the penalized Task 6 objective.

\noindent This defines exactly what "best" means in this report and why fallback/warning statuses appear in some scenario rows.


\Needspace{10\baselineskip}
\chapter{Material, Loading, and CAE Setup}


\noindent Each model is built from the selected Task 6 meridian profile and revolved into a thin-shell cooling-tower surface; Task 7 keeps the exact Task 6 geometry scale.

\noindent The global coordinate convention is \textit{Y}-up, with \textit{X/Z} as the horizontal plane.

\noindent Material assumptions are uniform across all cases: equivalent reinforced concrete with \textit{E = 33 GPa}, \textit{nu = 0.20}, density \textit{rho = 2500 kg/m³}, and shell thickness \textit{t = 0.20 m}.

\noindent Loading combines self-weight and one-direction wind. The reference wind speed is \textit{30.0 m/s}, giving \textit{q = 562.5 Pa} from \(q = 0.5\,\rho_{air}V^2\).

\noindent Wind is modeled as external pressure on the shell with windward pressure and leeward suction (not internal cabin pressure). The circumferential pressure law is:

\[
C_p(\theta) = \mathrm{clip}(0.8\cos\theta, -0.5, 0.8), \quad p(\theta) = q\,C_p(\theta)
\]

\noindent Boundary conditions represent the tower support at the foundation/piler ring: base nodes are fixed (\textit{U\_x = U\_y = U\_z = 0}), while the shell remains free elsewhere.

\noindent Each model uses one static step (\textit{STATIC\_WIND}) for combined loading and one linear buckling step (\textit{BUCKLING}) to extract the first instability modes about the preloaded state.

\chapter{Methodological Clarity and Global Ranking}


\Needspace{8\baselineskip}
\section{Methodological Clarity}


\noindent The global ranking is a rank-based weighted score on the refined results, designed to stay robust when one or two cases have extreme values.

\noindent For each metric, rank \textit{1} is best and rank \textit{24} is worst, with deterministic tie-breaks by scenario/algorithm identifiers.


\[
r_i^{(k)} = \operatorname{rank}_k(i)
\]


\[
S_i = 0.45\,r_i^{(b)} + 0.25\,r_i^{(d)} + 0.20\,r_i^{(s)} + 0.10\,r_i^{(a)}
\]


\[
J_i = S_i + P_i, \quad P_i \in \{0,10,20\}
\]


\noindent Here \(r_i^{(b)}\) is the buckling rank (higher buckling is better), \(r_i^{(d)}\) is the displacement rank, \(r_i^{(s)}\) is the stress rank, and \(r_i^{(a)}\) is the area rank (lower is better for the last three).

\noindent Penalty points are \textit{0} for engineering-feasible, \textit{10} for mathematical fallback, and \textit{20} for warning cases. The best model is the one with the lowest \textit{J\_i}.

\Needspace{8\baselineskip}
\section{Reproducibility and Fairness Controls}


\noindent Task 7 ranking is deterministic: every score is computed from the latest refined Abaqus results with fixed tie-breaks, so repeated report generation gives the same ordering.

\noindent Fairness is handled in two layers: warning/fallback cases remain visible in the global ranking through explicit penalties, while the engineering-eligible Top-3 table isolates decision-grade candidates.

\noindent This avoids the presentation ambiguity highlighted in Task 6 feedback by defining "best" as the minimum penalized weighted rank \textit{J\_i} and by keeping compliance status explicit in every comparison table.

\noindent Convergence confidence is still limited (\textit{0/24} all-pass), so the current winner must be treated as provisional screening output rather than final structural qualification.
